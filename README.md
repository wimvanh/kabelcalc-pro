# KabelCalc Pro BE

React/Vite PWA met kringtypes, kabelbibliotheek, automatische beveiligingssuggestie, PV/batterij/laadpaal-invoer, stoplichtvalidatie, PDF en XLSX-export.

## Starten
```bash
npm install
npm run dev
```

## Productie
```bash
npm run build
npm run preview
```

## Belangrijk
De ingebouwde waarden zijn conservatieve app-aannames en geen universele wettelijke tabellen. Controleer elk ontwerp aan het actuele AREI, fabrikantgegevens, installatiemethode, kortsluitvoorwaarden en keuring.
